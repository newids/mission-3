## A. 환경

- [ ] pyenv로 **Python 3.8 이상**을 설치했다 (권장 3.12.x)
- [ ] `pyenv local` 로 프로젝트 버전을 고정했다 (`.python-version` 존재)
- [ ] `python -m venv .venv` 로 가상환경을 만들고 활성화했다
- [ ] `pip list` 에 **외부 라이브러리가 없다**
- [ ] 가상환경 활성화 상태에서 `python main.py` 가 정상 실행된다

## B. 기능 — 데이터 구조 (R1)

- [ ] n×n 2차원 패턴/필터 저장 가능 (R1-1)
- [ ] 특정 위치 값 저장·조회 가능 (R1-2)
- [ ] **3×3, 5×5, 13×13, 25×25** 모두 처리 가능 (R1-3)

## C. 기능 — 모드 1 사용자 입력 (R2)

- [ ] 3×3 필터 A, B를 한 줄씩(공백 구분) 입력받아 저장 (R2-1)
- [ ] 3×3 패턴을 동일 방식으로 입력받아 저장 (R2-2)
- [ ] 행 수 불일치 검증 (R2-3)
- [ ] 열 수 불일치 검증 (R2-3)
- [ ] 숫자 파싱 실패 검증 (R2-3)
- [ ] 오류 시 안내 문구 출력 + **재입력 유도** (프로그램 종료 안 함) (R2-4)

## D. 기능 — 모드 2 JSON 처리 (R3)

- [ ] `data.json` 의 `filters.size_5 / size_13 / size_25` 로드 (R3-1)
- [ ] `patterns.size_{N}_{idx}` 의 `input`, `expected` 로드 (R3-2)
- [ ] 패턴 키에서 **N 추출 → 해당 필터 선택** (R3-3)
- [ ] 필터-패턴 **크기 일치 검증** (R3-4)
- [ ] 불일치 시 **케이스 단위 FAIL + 원인 메시지**, 프로그램 계속 진행 (R3-5)

## E. 기능 — 라벨 정규화 (R4)

- [ ] 표준 라벨 `Cross`, `X` 두 가지만 내부에서 사용 (R4-1)
- [ ] `expected`: `'+' → Cross`, `'x' → X` (R4-2)
- [ ] 필터 키: `'cross' → Cross`, `'x' → X` (R4-3)
- [ ] 콘솔 출력·PASS/FAIL 비교 모두 **표준 라벨 기준** (R4-4)

## F. 기능 — MAC 연산 (R5)

- [ ] 위치별 곱셈 후 전체 합산 구현 (R5-1)
- [ ] **NumPy 등 외부 라이브러리 없이 반복문으로 직접 구현** (R5-2)
- [ ] 점수를 `float` 로 반환 (R5-3)

## G. 기능 — 점수 비교 정책 (R6)

- [ ] epsilon 기반 비교 적용 (R6-1)
- [ ] `abs(a - b) < 1e-9` 이면 동점(UNDECIDED) 처리 (R6-2)

## H. 기능 — 판정 및 PASS/FAIL (R7)

- [ ] 두 점수 비교 후 판정 (동점은 UNDECIDED / 판정 불가) (R7-1)
- [ ] 각 패턴마다 **Cross 점수, X 점수, 판정** 출력 (R7-2)
- [ ] 판정 == expected → **PASS**, 아니면 **FAIL** 출력 (R7-3)

## I. 기능 — 성능 분석 (R8)

- [ ] ms 단위 측정 (R8-1)
- [ ] 크기별 **10회 이상 반복 후 평균** 출력 (R8-2)
- [ ] 측정 구간에 **I/O 미포함** (`time.perf_counter()` 사용) (R8-3)
- [ ] 표에 **크기 / 평균 시간(ms) / 연산 횟수(N²)** 포함 (R8-4)
- [ ] **3×3, 5×5, 13×13, 25×25** 4개 크기 모두 측정 (R8-5)

## J. 기능 — 결과 리포트 (R9)

- [ ] 콘솔에 **전체/통과/실패 수** 출력 (R9-1)
- [ ] 실패 케이스의 **식별자 + 사유 요약** 출력 (R9-2)
- [ ] README "결과 리포트" 섹션 **10줄 이상** (실패 원인 + 시간 복잡도) (R9-3)
- [ ] 실패 0건이어도 **왜 0인지** 서술 (R9-4)

## K. 실행 흐름 (R10)

- [ ] 시작 시 **모드 선택** 제공 (R10-1)
- [ ] 모드 1: `필터 A → 필터 B → 저장 확인 → 패턴 → MAC → 판정 → 성능분석(3×3)` (R10-2)
- [ ] 모드 2: `필터 로드 → 패턴 로드/검증 → MAC/판정/PASS-FAIL → 성능분석 → 결과 요약` (R10-3)

## L. 검증 시나리오 통과 ([05 문서](05-VERIFICATION.md))

- [ ] **T1** 모드1 정상 입력 → A=1.0, B=5.0, 판정 B
- [ ] **T2** 십자가 패턴 → A=5.0, B=1.0, 판정 A
- [ ] **T3** 동일 필터 2개 → 판정 불가
- [ ] **T4** 오류 입력 5종 → 안내 + 재입력 (크래시 없음)
- [ ] **T5** `data.json` 결과가 **정답표와 일치** (총 6 / 통과 3 / 실패 3)
- [ ] **T6** 성능 표 4행 + 연산 횟수 9/25/169/625
- [ ] **T7** 스키마 파손 6종 → 케이스 FAIL 또는 안내 후 정상 종료
- [ ] **T8** 잘못된 모드 선택 입력 → 재입력 유도
- [ ] **T9** `main.py` 에 외부 라이브러리 import 없음
