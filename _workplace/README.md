## 30초 요약

- 이 미션은 **MAC(Multiply-Accumulate) 연산**을 외부 라이브러리 없이 순수 Python으로 구현하는 과제다.
- 입력 패턴과 필터를 같은 위치끼리 곱해 전부 더한 값이 **유사도 점수**이고, 점수가 높은 쪽 필터로 판정한다.
- 제출물은 `main.py` 1개 + `README.md` 1개. 모드 2개(사용자 3×3 입력 / `data.json` 일괄 분석)를 지원해야 한다.
- **가장 중요한 사실**: 제공된 `data.json`은 6개 케이스 중 **3개가 의도적으로 부동소수점 동점(near-tie)** 이 되도록 설계돼 있다.
  epsilon 정책을 올바르게 적용하면 `3 PASS / 3 FAIL`이 나오며, **이 FAIL은 버그가 아니라 정답 동작**이다.
  자세한 근거와 원인 분석은 [03-data.json-분석.md](03-data.json-분석.md)에 있다.
